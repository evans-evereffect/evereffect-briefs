Site & SEO audit — goldinsuranceagency.com

Technical pass on the actual site, direct page source checked on each URL. Only 4 pages exist in the sitemap: homepage, /verify-my-agent, /jointheteam, /compgrid.

Real gap

/jointheteam is the whole recruiting funnel — and it's nearly empty

This is the page a recruiting-focused YouTube video would send people to. Right now it's one headline, one photo, and a phone number to text or call Daniel directly. No lead form, no video, no testimonials, no content depth, nothing for search to rank on.

This is the single most concrete, fixable thing on the whole site for exactly the angle Daniel is likely to want — it's the natural first deliverable if the recruiting angle confirms live.

Real gap

/compgrid is images only, zero crawlable text

The compensation-grid page (the actual pitch to a prospective agent on what they'd earn) is a stack of PNG graphics with no surrounding text. Not indexable, and the alt text on those images is blank — a screen reader gets nothing either.

Real gap

No meta description anywhere

Checked the homepage, /jointheteam, and /compgrid source directly — none of the three has a meta description tag. That's the snippet Google shows under the title in search results; right now Google is choosing that text for them.

Real gap

Generic titles, no local or schema signal

Every page title is generic ("HOME | Gold Insurance," "JOIN THE TEAM | Gold Insurance") — no city, no service keyword. Structured data on the homepage is a bare WebSite schema only; no LocalBusiness or InsuranceAgency markup despite being a real Carmel, IN business with a phone number and address.

Real gap

Half the images have no alt text

42 images across the site; 22 have a blank alt="" attribute. Most of the rest use the raw filename as alt text (e.g. "4547.png") instead of a description — not meaningfully better for accessibility or image search.

Working fine

The basics that aren't broken

robots.txt is a standard, unmodified Wix default — allows crawling, declares the sitemap, no accidental blocking. Canonical tag is present and correct. Sitemap was last touched Aug 5, 2026, so the site is being actively maintained, just not optimized.

How to use this on the call. Don't lead with the SEO audit — it's website work, and the ask was about YouTube. But if the conversation turns to "what else could help," the /jointheteam gap is a genuinely strong, honest example of the same discipline EverEffect applies everywhere: real audit, real page, real fix, not a generic pitch.
